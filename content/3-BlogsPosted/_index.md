This section will list and introduce the blogs you have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). 

### [Blog 1 - Understanding AWS Amplify & Why It's Perfect for Personal Projects](3.1-Blog1/)
This blog introduces AWS Amplify as a powerful set of tools and services that help developers build full-stack Web and Mobile applications quickly on AWS infrastructure. It highlights key features like built-in Authentication, flexible API & Database setups, and automated CI/CD, making it an ideal choice for student assignments, demos, and MVPs without requiring deep DevOps knowledge.

### [Blog 2 - AWS Cost Tips for Beginners: Avoiding End-of-Month Bill Shock](3.2-Blog2/)
This blog provides essential tips for AWS beginners to avoid unexpected billing surprises. It covers crucial best practices such as setting up AWS Budgets and Billing Alerts, utilizing the AWS Free Tier correctly, cleaning up unused resources (like unattached EBS volumes and idle Elastic IPs), and regularly monitoring expenses with AWS Cost Explorer.

### [Blog 3 - Building a Simple, Secure Static Website with S3 + CloudFront + Route 53](3.3-Blog3/)
This blog outlines the industry-standard architecture for hosting static websites on AWS. It details the step-by-step process of storing files in Amazon S3, accelerating and securing content delivery with Amazon CloudFront (including Origin Access Control and free ACM SSL certificates), and routing custom domains using Amazon Route 53, all while maintaining a highly scalable, near-zero cost serverless setup.
